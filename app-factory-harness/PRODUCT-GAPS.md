# 群内 Agent 产品差距与迭代

比较标准来自本项目用户描述的 Grok bot 式体验，不是对某个外部产品未核实功能的宣称。

| 产品缺口 | 当前进展 | 后续验收 |
|---|---|---|
| 群内没有 Agent 档案入口 | 已增加群内能力与设定侧栏 | 实际浏览器操作验收 |
| 看不到真实 Skill | 已接 Harness scoped catalog，显示观测时间、完整性、正文与来源 | 目录刷新和跨角色验收 |
| Skill 不能编辑 | 本项目 Skill 可编辑成新草稿，启用与版本冲突检查 | 外部来源 Skill 的显式复制编辑流程 |
| 保存与生效混淆 | 显示保存角色版本和实例加载版本 | 空闲安全热加载；当前需重启 |
| 每轮都刷群 | 仅原生 group_publish 成功事件公开；内部文字不群发 | 真实多轮公开/静默质量评测 |
| 聊天与任务脱节 | 执行步骤、版本预览、图片引用已有 | 群内聚合任务面板、暂停/取消闭环 |
| 缺少实时共同预览 | 真实截图与阶段清单已有 | 持续可交互预览、圈选区域、操作录屏 |
| 缺少版本安全感 | 反馈轮次编号已有 | 隔离代码分支、差异对比、一键回退；轮次不是代码版本 |
| 多任务争抢资源 | Router 提示约束串行 | App 写入及模拟器强制租约锁 |
| 只有问答没有团队理解 | 持久目标、分层记忆已有 | 讨论/决定/任务关系，会议行动项与冲突处理 |
| 记忆质量不可控 | 来源、范围、版本、候选归并已有 | 相关性检索、过期、冲突解释、用户纠正传播 |
| Skill 自我进化欠验证 | 可自主写草稿、查看并启用 | 自动评测、成功率、回退及晋升策略 |
| bot 模板不够完整 | 文本角色与 Skill 导入导出已有 | 依赖清单、版本兼容、脱敏检查、权限预览 |
| 工作中断后恢复不自然 | 原生 session 恢复，副作用不自动重放 | 检查点与证据核对后无重复继续 |
| 真正多人边界缺失 | 本地模拟身份 | 飞书群/线程身份、权限、重试与外发策略 |
| 品质依赖模型自报 | 同版本截图和多尺寸覆盖检查已有 | 独立视觉/交互回归与失败定位 |

先完善高频闭环：看当前成果 → 指出一处问题 → 改这一处 → 看差异 → 接受或回退。后台多 Agent 是实现方式，不应成为用户必须理解和管理的负担。
